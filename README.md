# Daily Update Website

A simple working website to track:

- Daily updates (what you did each day)
- College attendance (present/absent with subject)
- Writeups and teacher checkup status

## Features

- Add daily updates with date, task title, and notes
- Add attendance records by date, subject, and status
- Attendance summary: total, present, absent, percentage
- Add writeups with topic, full writeup text, teacher name, and teacher remarks
- Teacher checkup status tracking (Pending/Checked)
- Writeup summary: total, pending, checked
- Toggle writeup status quickly (Pending <-> Checked)
- Search daily updates instantly
- Filter attendance by Present/Absent
- Search and filter writeups
- Dark mode toggle (theme preference saved)
- Delete individual attendance rows
- Delete individual daily updates
- Clear all updates or all attendance data
- Data saved in browser storage and persists after refresh

## Run

1. Open `index.html` directly in your browser.
2. Start entering daily updates and attendance.

## Notes

- Data is stored on the same browser/device.
- If you clear browser site data, records will be removed.
- If localStorage is blocked by browser settings, app uses cookie fallback.
